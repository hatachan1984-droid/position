# ⚾ 寺町トンネルズ カバーリング・バックアップ学習アプリ

少年野球チーム「寺町トンネルズ」のための**実践的な守備学習Webアプリケーション**です。

## 🎯 プロジェクト概要

- **チーム名**: 寺町トンネルズ
- **チームカラー**: 青系（#2563eb）
- **対象**: 少年野球選手＋保護者（20〜30人）
- **デバイス**: スマホ中心（レスポンシブデザイン）
- **学習内容**: カバーリングとバックアップの動き

## 🌟 コンセプト

従来の「定位置」学習ではなく、**打球方向別のカバーリングとバックアップの動き**を学ぶ実践的なアプリです。

### なぜカバーリング・バックアップなのか？

野球の守備は、ただ定位置に立つだけではありません：
- 🔴 **打球処理**：誰が打球を処理するか
- 🔵 **カバーリング**：送球先をカバーする（実線矢印）
- 🟡 **バックアップ**：エラーに備えて後方に位置する（点線矢印）
- 🟢 **ベースカバー**：ベースに入る

これらの連携プレーを理解することで、チーム全体の守備力が向上します。

## ☁️ データ管理の仕組み

### クラウドデータベース（RESTful Table API）
- **自動同期**: ログイン・クイズ回答・ポジション変更時に自動保存
- **複数端末対応**: 同じニックネーム＋パスワードで全端末からアクセス可能

### オフライン対応
- localStorageにもデータを保存
- ネット接続が復旧次第、自動的にクラウドへ同期

  - 後方互換性確保：既存データは現在のポジションに自動移行
